Bienvenido a la Plataforma de Fundamentos Web

Este proyecto es un entorno educativo diseñado para desglosar la complejidad del desarrollo moderno. Aquí exploramos desde la lógica pura hasta la visualización en el navegador.

Contenido de las Secciones

A través del menú de navegación, podrá acceder a los siguientes pilares de estudio:

🧠 Paradigmas y Arquitectura

Estudio del paradigma Imperativo (C/Pascal) vs. Declarativo y la POO. Además, analizamos el modelo Cliente-Servidor y la centralización de datos.

🏗️ Todo sobre HTML

Diccionario técnico de etiquetas, desde metadatos (<head>) hasta contenido multimedia y la importancia de la semántica para el SEO y la accesibilidad.

🎨 Diseño con CSS

Exploración de las tres formas de incluir estilos, el uso de unidades relativas (rem, em) y absolutas, y la lógica del Modelo de Cajas.

📝 Formularios y Evaluación

Implementación de controles de entrada de datos y un test de conocimientos interactivo para validar el aprendizaje de los módulos anteriores.
