¿Que es Javascirpt?

Javascript es un lenguaje de programación, o lo que es lo mismo, un mecanismo con el que podemos decirle a nuestro navegador que tareas debe realizar, en que orden y cuantas veces.

Muchas de las tareas que realizamos con HTML y CSS se podrían realizar con Javascript. De hecho, es muy probable que al principio nos parezca que es mucho más complicado hacerlo con Javascript, y que por lo tanto no merece la pena. Sin embargo, con el tiempo veremos que Javascript nos ofrece una mayor flexibilidad y un abanico de posibilidades más grande, y que bien usadas, pueden ahorrarnos bastante tiempo.

Para comprenderlo, un ejemplo muy sencillo sería el siguiente:

<div class="item">
  <p>Número: <span class="numero">1</span></p>
  <p>Número: <span class="numero">2</span></p>
  <p>Número: <span class="numero">3</span></p>
  <p>Número: <span class="numero">4</span></p>
  <p>Número: <span class="numero">5</span></p>
</div>

Imaginemos que tenemos que crear una lista de números desde el 1 hasta el 500. Hacerlo solamente con HTML sería muy tedioso, ya que tendríamos que copiar y pegar esas filas varias veces hasta llegar a 500. Sin embargo, mediante Javascript, podemos decirle al navegador que escriba el primer párrafo <p>, que luego escriba el mismo pero sumándole uno al número. Y que esto lo repita hasta llegar a 500.

De esta forma y con este sencillo ejemplo, con HTML habría que escribir 500 líneas mientras que con Javascript no serían más de 10 líneas.

1. Formas de Enlazar JavaScript

Dependiendo de dónde coloques el código, el navegador lo leerá de forma distinta:

Script Externo (Recomendado): Usando el atributo src.

Script Interno: Escribiendo el código directamente entre etiquetas <script> en el HTML.

Atributos de Evento: (No recomendado por desordenado) directamente en el HTML: <button onclick="alert('Hola')">.

Aunque la forma externa es la mejor, aquí tienes cómo se verían las tres en un archivo HTML:

<!-- 1. Externa (La mejor) -->
<script src="app.js"></script>

<!-- 2. Interna (Para pruebas rápidas) -->
<script>
  console.log("Hola desde el HTML");
</script>

<!-- 3. Atributo (No recomendada, pero existe) -->
<button onclick="alert('¡Click!')">Púlsame</button>

2. Manejo de Variables (El Triunvirato)

Históricamente JavaScript ha evolucionado en cómo guarda datos:

let (Moderno): Tiene "scope" de bloque (solo vive dentro de las llaves {} donde se creó). Ideal para valores que cambian.

const (Moderno): Igual que let, pero su valor es inmutable (no puedes reasignarlo). Úsalo por defecto siempre que puedas.

ejemplo de como se usaría:

const nombre = "Alex"; // No cambiará
let puntos = 10;       // Puede cambiar

puntos = puntos + 5;   // Correcto
// nombre = "Juan";    // Error: No puedes reasignar una constante

3. Condicionales

(`if` / `else`)

Son estructuras de control que permiten al programa tomar diferentes caminos basándose en si una condición es verdadera (`true`) o falsa (`false`).

ejemplo:

let hora = 14;

if (hora < 12) {
    console.log("Buenos días");
} else if (hora < 20) {
    console.log("Buenas tardes");
} else {
    console.log("Buenas noches");
}

(switch): Para comparar una variable contra muchos valores posibles.

ejemplo

let fruta = "pera";

switch (fruta) {
    case "manzana": console.log("Roja"); break;
    case "pera": console.log("Verde"); break;
    default: console.log("No conozco ese color");
}

El Operador Ternario (Sintaxis corta)

Perfecto para decisiones simples de "esto o aquello" en una sola línea.

ejemplo:

const resultado = (nota > 5) ? "Aprobado" : "Suspenso";

Short-circuit (`&&` / `||`): Ejecuta algo solo si se cumple la condición.

ejemplo:

esUsuario && iniciarSesion(); // Si esUsuario es true, ejecuta la función.

4. Todas las formas de Ciclos (Loops)

for (Clásico): Control total por índice.

for (let i=0; i<5; i++) { ... }

while: Repite mientras la condición sea verdadera.

while (condicion) { ... }

do...while: Ejecuta al menos una vez y luego pregunta.

do { ... } while (condicion);

for...of: Para recorrer valores de un array.

for (let fruta of frutas) { ... }

for...in: Para recorrer propiedades de un objeto.

for (let llave in objeto) { ... }

forEach: Método de array para ejecutar una función por cada elemento.

array.forEach(el => console.log(el));

5. Todas las formas de Funciones

Función Declarativa: Es la forma clásica. Tiene nombre y se puede llamar antes de ser escrita.

// Llamada antes de la definición
saludar(); 

function saludar() {
    console.log("Hola desde una función declarativa");
}

Función de Expresión: Aquí la función se guarda dentro de una variable. A diferencia de las declarativas, no tienen hoisting; el código dará error si intentas usarlas antes de definirlas.

const despedir = function() {
    console.log("Adiós, nos vemos");
};

despedir(); // Se llama a través de la variable

Flecha (Arrow): Es una forma moderna y simplificada de escribir funciones. Son más cortas visualmente y se guardan dentro de constantes o variables.

const saludar = (nombre) => `Hola, ${nombre}!`;

console.log(saludar("Alex")); // Imprime: Hola, Alex!

Funciones Anónimas

Son funciones que no tienen nombre. Normalmente no viven solas, sino que se pasan como "argumento" a otra función (como en los ciclos o eventos).

setTimeout(function() {
    console.log("Pasaron 2 segundos");
}, 2000);

Funciones IIFE (Ejecución Inmediata)

Su nombre viene de Immediately Invoked Function Expression. Son funciones que se declaran y se ejecutan solas al instante. Se envuelven en paréntesis.

( function() {
    console.log("Me ejecuto sin que nadie me llame");
})();

Funciones Asíncronas (async / await):
Se usan para tareas que tardan tiempo, como pedir datos a una base de datos o a una página web. Permiten que el código "espere" sin trabar todo el programa.

async function obtenerDatos() {
    console.log("Cargando...");
    // await hace que el código espere aquí hasta que lleguen los datos
    let respuesta = await fetch('https://api.ejemplo.com');
    console.log("¡Datos recibidos!");
}
