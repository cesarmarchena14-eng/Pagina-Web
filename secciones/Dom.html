1. ¿Qué es el DOM (Document Object Model)?

El DOM es una interfaz de programación estructurada que el navegador genera automáticamente en la memoria RAM cuando carga un archivo HTML. No es parte del lenguaje JavaScript en sí, sino una API que le permite a JavaScript conectarse, leer, alterar y dinámicamente cambiar la estructura, estilos o contenidos de las etiquetas en tiempo real sin recargar la pestaña.

2. Estructura Jerárquica: El Árbol de Nodos

Para el navegador, cada elemento de tu documento es un objeto interactivo llamado Nodo. Estos nodos se organizan de forma piramidal:

  • Document: El nodo raíz que representa a toda la página web completa.
  • Element: Etiquetas HTML propiamente dichas (<h1>, <div>, <p>).
  • Text: El contenido de texto plano que vive dentro de una etiqueta.
  • Attribute: Las propiedades de configuración (como una clase class="" o un enlace href="").

3. El Método: document.getElementById()

¿Qué hace?: Inspecciona el árbol completo del DOM y captura un **único elemento** basándose de forma estricta en su atributo id. Es el selector más veloz y optimizado para componentes únicos de la interfaz.

Ejemplo Práctico:

// 1. Capturamos el elemento único por su ID
let miTitulo = document.getElementById('titulo-principal');

// 2. Modificamos su texto interno en caliente
miTitulo.textContent = "¡Texto cambiado con JavaScript!";

4. El Método: document.querySelector()

¿Qué hace?: Es el selector moderno polivalente. Devuelve únicamente el **primer elemento** de la página que coincida con la regla de CSS que le proveas (ya sea una etiqueta, una clase con punto o un ID con almohadilla).

Ejemplo Práctico:

// Captura el primer elemento que tenga asignada la clase '.btn-nav'
let primerBoton = document.querySelector('.btn-nav');

// Modificamos sus estilos inline directamente en la memoria
primerBoton.style.backgroundColor = '#3282b8';

5. El Método: document.querySelectorAll()

¿Qué hace?: Rastrea toda la interfaz y extrae **absolutamente todos** los elementos que cumplan con la regla de CSS dada, empaquetándolos dentro de una colección indexada estática llamada NodeList (la cual podemos iterar con ciclos).

Ejemplo Práctico:

// Selecciona todas las etiquetas de enlace 'a' del menú
let enlacesMenu = document.querySelectorAll('a');

// Iteramos la colección para ocultar todos los botones de golpe
enlacesMenu.forEach(function(enlace) {
    enlace.style.display = 'none';
});

6. El Método: addEventListener()

¿Qué hace?: Es el escuchador de eventos nativo. Se ancla a una etiqueta y monitoriza en segundo plano las acciones del usuario (un clic, el envío de un formulario, pulsaciones de teclas). Cuando la acción se produce, ejecuta una función de callback inmediatamente.

Ejemplo Práctico:

let botonGuardar = document.querySelector('#btn-guardar');

// Escuchamos la acción 'click' y disparamos una rutina
botonGuardar.addEventListener('click', function() {
    alert("¡Evento click capturado a través del árbol del DOM!");
});

7. El Método: document.createElement()

¿Qué hace?: Fabrica una etiqueta HTML completamente nueva desde cero directamente en la memoria virtual del navegador. El elemento se queda flotando en RAM de manera temporal hasta que se ordene su renderizado en la página.

Ejemplo Práctico:

// Generamos una etiqueta de párrafo '<p>' en la memoria volátil
let nuevoParrafo = document.createElement('p');

nuevoParrafo.textContent = "Este bloque es un nodo inyectado dinámicamente.";

8. El Método: appendChild()

¿Qué hace?: Toma un nodo o etiqueta que tengas guardado en memoria (por ejemplo, uno creado con createElement) y lo **inserta físicamente en la pantalla**, colocándolo como el último hijo disponible dentro de un elemento contenedor.

Ejemplo Práctico:

// 1. Ubicamos el contenedor principal de nuestra wiki
let cajaContenido = document.querySelector('.content-wiki');

// 2. Insertamos el párrafo flotante dentro de la caja visible
cajaContenido.appendChild(nuevoParrafo);
